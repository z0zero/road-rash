# Original game inspired by Road Rash, without EA's name or assets

Road Rash's name, logo, graphics and music belong to Electronic Arts, while this game is deployed publicly and lives in an MIT-licensed repository. So the game gets its own title, and all of its art and audio are our own or CC0; only the gameplay mechanics and feel follow Road Rash, and `road-rash` is just the repository's codename. Using the original name or assets would risk a takedown and could not be licensed under MIT; on 2026-10-29, "Road Rash" was still a live EA trademark for video game software (US Reg. No. 4321323).
