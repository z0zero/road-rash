# Stylized low-poly 3D instead of pseudo-3D sprites

The original Road Rash draws its road and riders as pseudo-3D scaled sprites, but we want a modern look and have no illustrator for the many hand-drawn sprite frames (riders punching and kicking from every angle) that approach needs. So the game renders a real-time 3D world with Three.js in a stylized low-poly style, with models built in code or taken from CC0 packs, while the gameplay stays arcade rather than physics simulation. Realistic 3D was rejected as too heavy both to build and to run in a browser.
