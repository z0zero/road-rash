# Difficulty is the race's one configuration besides its seed

v1.0.0's race is fair to a player who rides a decent line or hits back, but a first-timer rides at the back alone, and a player who has qualified wants more. Rather than make the one race easier for everyone, the game offers a difficulty, Easy, Normal or Hard, chosen on the title screen, and the Race module takes it with the seed: `createRace({ seed, difficulty })`. This is the race configuration ADR 0004 said would come when something needed one. A difficulty is a name, not numbers the game passes in: each is a small, fixed set of named tuning values in the Race module (the opponents' pace, how often they attack the player, their breathers, their patience and catch-up), so every race the game can create is one the Race module's tests can create, and the same seed, difficulty and inputs replay the same race. Only the opponents change: the track, the traffic and the cops are the same on every difficulty. Normal is v1.0.0's race, byte for byte, and the default, so a seed alone still replays it, and `?seed=` replays take `&difficulty=`. Each difficulty keeps its own personal best, since times on one don't compare with times on another, and a v1.0.0 save's personal best becomes Normal's. A difficulty must not grow into a career mode's settings, such as other tracks or upgrades: those would revisit this decision.
